# ev-charging-infrastructure-siting
Business Analytics project to identify optimal EV charging station locations using geospatial analysis, machine learning, demand forecasting, and ROI evaluation.


## Project Overview

This project aims to identify the most suitable locations for installing Electric Vehicle (EV) charging stations in a city using Business Analytics, Geospatial Analysis, and Machine Learning.

The system evaluates candidate locations based on:

- EV registration density
- Traffic patterns
- Parking availability
- Existing charging stations
- Grid capacity
- Installation cost

Finally, it ranks locations by expected utilization, ROI, and estimated payback period.

---

## Objectives

- Analyze EV charging demand
- Recommend optimal charging station locations
- Predict charger utilization
- Estimate installation cost and revenue
- Calculate ROI and payback period
- Develop an interactive dashboard
